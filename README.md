# BTC Auto Trader (Paper Trading)

**Nur Simulation – kein echtes Geld.**

Sehr einfache Streamlit-App:

1. Du stellst nur ein, wie viel Geld eingesetzt werden soll.
2. Das Programm tradet danach automatisch.
3. Es zeigt dir nur die ausgeführten Trades an.

## Starten

```bash
pip install -r requirements.txt
streamlit run app.py
```

Oder einfach über [Streamlit Community Cloud](https://share.streamlit.io) mit diesem Repository deployen.

## Wichtiger Hinweis

Dies ist reines Paper-Trading zu Lernzwecken. Es gibt keine Gewinn-Garantie. Echtes Trading ist riskant und kann zum Totalverlust führen.
